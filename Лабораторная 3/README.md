## GPSS World

Для контрольных опытов можно открыть `models/part1/System33.gps` или `models/part2/ClosedM3.gps` и выполнить **Command → Create Simulation**. Для системы 33 в журнале симуляции последовательно выполните команды `START 10000,NP`, `RESET` и `START 120000` через **Command → Custom**. Замкнутая модель содержит команды запуска в исходнике. Контрольные отчёты лежат в `out/part1/raw/baseline/` и `out/part2/raw/`, снимки показаны в разделе «Работа с моделями в GPSS World».

Для повторения параметрических серий из корня УИР 3 подготовьте модели в новые рабочие каталоги.

```bash
python app/native_campaign.py part1 gp_runs_p1
python app/native_campaign.py part2 gp_runs_p2
```

Для каждого созданного `.gps` выполните **Command → Create Simulation**. После сообщения `Ready` и регистрации процедуры `RunCampaign` выполните `CONDUCT RunCampaign()` через **Command → Custom**. Журнал покажет `Experiment ended`, а рядом с моделью появится `native_results.csv` с последней строкой `COMPLETED`. Для парной серии используйте выгрузку основной серии сети, чтобы подобрать интенсивность поступления по измеренной производительности замкнутой сети.

```bash
python app/native_campaign.py part2 gp_runs_paired --warmup 100000 --duration 800000 \
  --paired-from gp_runs_p2/network/native_results.csv
```

## Обработка сохранённых результатов

Нужны Python 3.10 или новее, NumPy и Matplotlib. Для входной трассы используется файл варианта 207 из папки УИР 1 в этом репозитории. Скрипты читают выгрузки и стандартные отчёты GPSS World, пересчитывают таблицы и строят графики.

```bash
python app/part1_reports.py
python app/part1_figures.py
python app/part1_tex.py
python app/part2_native.py --campaign out/part2/gpss/campaigns/network.csv \
  --campaign out/part2/gpss/campaigns/matched.csv
```

## Результат

В контрольном опыте GPSS World для системы 33 суммарная загрузка составила 1,518697, вероятность потери — 0,491417, среднее пребывание — 10,405 с. Максимальное относительное расхождение с УИР 2 по шести показателям составило 0,79%. Для M3 узким местом является У3, предельная производительность — 1/14 заявки/с. При допуске 2% по производительности критическая популяция замкнутой сети равна шести.
