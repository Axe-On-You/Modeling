### Цель работы
Изучение методов обработки и статистического анализа результатов измерений на примере заданной числовой последовательности (ЧП). Оценка числовых моментов, выявление свойств последовательности на основе корреляционного анализа, а также аппроксимация закона распределения по двум числовым моментам случайной величины.

### Поставленные задачи
1. Рассчитать числовые характеристики (Мат. ожидание, Дисперсия, СКО, Коэффициент вариации) и доверительные интервалы для исходной ЧП (при N = 10, 20, 50, 100, 200, 300).
2. Выполнить графический и автокорреляционный анализ для подтверждения случайности последовательности.
3. Построить гистограмму распределения.
4. Выполнить аппроксимацию закона распределения (определить закон и рассчитать его параметры).
5. Написать генератор случайных чисел по найденному закону.
6. Сравнить сгенерированную последовательность с исходной (статистически и графически).

### Что было сделано (Ход работы)
- С помощью скриптов на Python был проведен полный математический и статистический анализ заданной последовательности (300 значений).
- Выявлено, что коэффициент вариации $V \approx 2.43 > 1$, на основании чего для аппроксимации был выбран **гиперэкспоненциальный закон распределения**.
- По методу моментов найдены параметры распределения: $q \approx 0.2319$, $t_1 \approx 44.32$, $t_2 \approx 1.61$.
- Разработан алгоритм генерации на основе метода обратной функции и композиции двух экспоненциальных распределений.
- Сгенерирована новая последовательность, для которой также рассчитаны все статистические характеристики.
- Построены графики автокорреляции, линейные графики и гистограммы для наглядного сравнения.
- Взаимная корреляция между последовательностями $r \approx -0.05$ подтвердила независимость сгенерированной выборки.
- Оформлен итоговый отчет в формате LaTeX.

### Структура репозитория
* `Вариант_207.csv` — исходные данные.
